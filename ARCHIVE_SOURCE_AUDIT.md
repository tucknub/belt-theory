## Binding caption and distribution rules

When a source page distinguishes the photographed event date from a later upload, transfer or publication date, Belt Theory captions the event and discloses later provenance in the credits record. When an event date is unknown, Belt Theory does not invent one. A jurisdiction-limited public-domain analysis does not qualify an image for the global production manifest.
