# Belt Theory — Design Preservation Rule

## Official scope

The Authentic Archive work is an **imagery and evidence retrofit**, not a wholesale redesign of Belt Theory.

The existing production visual system remains the approved baseline. The user explicitly approved and wants to preserve the established style, including its cinematic presentation, typography, color system, layouts, data hierarchy and overall personality.

## Preserve without unnecessary change

The following should remain intact unless a specific accessibility, performance or factual problem requires a narrowly scoped correction:

- Belt Theory branding and wordmark treatment
- Black, charcoal and championship-gold visual system
- Promotion-specific accent colors
- Existing typography scale and oversized editorial headlines
- Page hierarchy and navigation
- Hero composition and principal copy
- Scorecard and report structure
- Data rails, verdict blocks, stat treatments and comparison modules
- Existing charts, canonical metrics and editorial conclusions
- Spacing rhythm, borders, panels, transitions and responsive behavior
- The premium sports-documentary and data-journalism feel already established

## Changes that are in scope

- Replace synthetic or misleading historical imagery with authentic, rights-cleared photography
- Replace generic synthetic arenas when they imply a real event, promotion or historical setting
- Add visible captions, dates, event context, creator credit and license references
- Add reusable photo, credit, license and focal-crop components
- Adjust image containers only where needed to preserve faces, bodies, hands, clothing and championship belts
- Add self-hosted responsive image derivatives and performance metadata
- Add abstract AI-assisted texture or atmosphere only outside authentic subjects
- Correct historical labels, alt text, source notes and image-context errors

## Changes that are out of scope

- Rebuilding every page into a different magazine layout
- Replacing the established homepage composition merely because authentic photos are being added
- Removing or minimizing the data presentation that defines Belt Theory
- Changing approved copy, findings or canonical numbers without a research correction
- Introducing a new brand identity, typography system or general aesthetic
- Allowing photography to turn the site into a generic wrestling-news or fan-gallery layout
- Placing credits or decorative overlays across faces, bodies, hands, clothing or championship belts

## Implementation rule

Start from the approved production page and swap the imagery **in place** wherever practical.

Use the archival homepage prototype as a testing ground for:

- photo crops
- caption and credit styling
- license badges
- focal-point behavior
- photo/data pairings
- responsive image treatment

Do not treat the prototype as an automatic replacement for the production homepage layout.

## Review question

For every proposed change, ask:

> Is this necessary to make the imagery authentic, correctly credited, historically accurate, accessible or performant?

If the answer is no, preserve the existing design.

## Final principle

> Keep the Belt Theory style. Replace fake history with real history.
